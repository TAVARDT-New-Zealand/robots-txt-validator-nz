# Robots.txt Validator

[![Robots.txt Validator](https://img.shields.io/badge/TAVARDT-Robots.txt-5b3cf5.svg)](https://tools.tavardt.com/nz/robots-txt-validator/)
[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)

Independent crawl governance and robots.txt audit suite for New Zealand digital assets, checking parser safety and crawler directives.

Engineered and maintained by the digital integrity and search systems division at **TAVARDT New Zealand**.

***

## Robots.txt Audit Capabilities

* **De-indexing Risk Discovery**: Guards against catastrophic search engine blockades in New Zealand websites.
* **Search Bot and AI Scraper Governance**: Tailors permissions for Googlebot, Bingbot, and autonomous AI bots.
* **Sitemap Declaration Integrity**: Validates the presence, formatting, and responsiveness of sitemap pointers.
* **Directive Integrity Checks**: Inspects disallow parameters, path wildcards, and crawl timing directives.
* **Crawl Governance Rating**: Objective 0 to 100 rating accompanied by prioritized remediation guidance.

***

## Installation and Execution

Requires Python 3.8 or higher with standard library.

```bash
git clone https://github.com/TAVARDT-New-Zealand/robots-txt-validator-nz.git
cd robots-txt-validator-nz
python robots_validator.py https://example.co.nz
```

For JSON format:

```bash
python robots_validator.py https://example.co.nz -json
```
